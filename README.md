## About This Repository (V1 Legacy Source)

This repository contains the standalone GPL-3.0 legacy source tree of **WaEnhancer** for Android preference customization, media controls, status utilities, and local privacy tweaks.

### Core Capabilities
* **Privacy & Security:** Hide read receipts, typing indicators, view-once bypass, and anti-revoke message protection.
* **Media & Status Tools:** Download statuses, send uncompressed media, and extend status duration limits.
* **UI Customization:** Customize tabs, chat filters, and interface elements locally.

## Requirements

* Android 9.0 (Pie) or higher
* Rooted device with Magisk, KernelSU, or APatch
* LSPosed Framework installed and active

### Build from Source

```sh
./gradlew assembleDebug
```
